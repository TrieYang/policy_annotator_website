### **Task**
Generate a high-level executive summary of the model card's compliance status across all evaluated policies. This summary should identify common themes, critical gaps, and provide strategic recommendations for improving overall compliance.

### **Instructions**
- Input will be a JSON object containing summaries from individual policy evaluations:
  ```json
  {
    "policy_summaries": {
      "POLICY1": "full markdown summary...",
      "POLICY2": "full markdown summary...",
      ...
    }
  }
  ```

- Your task is to:
  1. Analyze all policy evaluation summaries
  2. Identify all major compliance gaps
  3. Generate a concise executive summary
  4. Provide high-level strategic recommendations
  in a friendly, gentle, neutral tone. Do not be too harsh in terms of your choice of language.

### **Highlighting Instructions**
To improve readability, use the `highlight()` function around key phrases that should stand out. Examples:
- `highlight(critical non-compliance)` - for severe issues
- `highlight(systematic failures)` - for widespread problems
- `highlight(fundamental regulatory requirements)` - for core requirements
- `highlight(complete absence of legal documentation)` - for missing elements
- `highlight(immediate remediation required)` - for urgent actions
- `highlight(high-risk legal violations)` - for serious compliance issues

Use highlighting sparingly and strategically - only highlight the most important concepts that help users quickly understand the key issues and required actions.

### **Priority Classification Guidelines**
When assigning priority levels to compliance gaps, use the following criteria:

- **High**: Legal violations, regulatory non-compliance, or issues that could result in significant legal/financial risks. These require immediate attention and remediation.
- **Medium**: Compliance gaps that may lead to future risks or partial non-compliance. These should be addressed within a reasonable timeframe to prevent escalation.
- **Low**: Minor improvements or best practice recommendations that enhance compliance but don't pose immediate risks. These can be addressed as resources permit.


### **Output Format**
```
**Current Compliance Status:**  
Brief 3–4 sentence overview of the model card's overall compliance status across all evaluated policies. Use highlighting for key issues and critical actions needed.

**Compliance Gaps and To-dos**  
Present major compliance issues in a markdown table format as shown below. Each row represents a key gap. Present actionable recommendations to address each issue.

| Compliance Gap                              | Description                                                                | To-dos                                           | Priority |
|--------------------------------------------|-----------------------------------------------------------------------------|---------------------------------------------------|---------|-------------------|
| Short title of the issue — 5–10 words      | Specify which exact articles under which policy are violated and why, explaining the gap in 2–3 sentences      | Provide clear, actionable remediation steps directly addressing the described gap; keep under 20 words each	| High / Medium / Low based on legal risk and potential harm    |

```

### **Formatting Rules**
- Keep the tone professional and constructive
- As an overall summary, highlight patterns across different policies
- Prioritize the most critical issues
- Keep recommendations strategic and high-level
- Do not include any headings above "Current Status" - the UI will handle the main title
- For violation details, extract the exact article numbers, scores, and descriptions from the policy summaries
- Only include violations with scores < 5 (non-compliant items)
- Use the exact content from the policy summaries, not newly generated information
- Use highlighting strategically to emphasize key compliance issues and critical actions needed

### **Example Input**
```json
{
  "policy_summaries": {
    "AIDA": "#### 🟠 AIDA – Partial Compliance...[full summary with violation details]",
    "CCPA": "#### 🟠 CCPA – Partial Compliance...[full summary with violation details]"
  }
}
```
